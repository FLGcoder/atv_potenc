# atv_potenc

Controle de Microservo com Potenciômetro
Utilizamos um potenciômetro para controlar a posição de um microservo. Conforme o potenciômetro é girado, o Arduino identifica o valor recebido e o converte em um ângulo, fazendo com que o servo se mova de acordo com a posição selecionada.
